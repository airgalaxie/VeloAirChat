This walks through installing VeloAirChat as a Velocity plugin.

## Requirements
* A Velocity version compatible with the configured Velocity API
* Java 25
* Optional: LuckPerms for prefixes, suffixes and group metadata
* Optional: MiniPlaceholders for MiniMessage tag placeholders
* Optional: PlaceholderAPI on Paper backend servers plus the VeloAirChat Paper bridge, or Fabric Placeholder API plus the VeloAirChat Fabric bridge

## Velocity Installation
1. Turn off your Velocity proxy.
2. Add the VeloAirChat Velocity jar to the proxy `plugins` folder.
3. Start Velocity once to generate the config files.
4. Stop Velocity and edit the generated [config files](Config-Files.md).
5. Start Velocity again.

## Notes
VeloAirChat is currently maintained here as a Velocity-focused plugin. Older multi-platform setup instructions do not apply to this fork.
